DANSCOMFX Algorithmic Framework

DANSCOMFX is an ongoing personal study into automated risk parity and systematic trend-following. Rather than attempting to predict price direction subjectively, the architecture enforces strict algorithmic discipline:

  • Strict Mathematical Position Sizing: Calculates lot sizes dynamically based on account equity and Average True Range (ATR) so that no individual position risks more than 1% of total portfolio equity.
  • Circuit Breaker Drawdown Lockout: Enforces an automated lockout if daily losses reach 3%, terminating order generation to prevent emotional over-trading.
  • Webhook Routing Architecture: Bridges TradingView alerts to MetaTrader 5 execution terminals via lightweight JSON webhooks.
Current Status: Forward paper testing on demo environment; evaluating execution latency and slippage behavior.
Technical API Prototype WebSockets / ES6+

Deriv WebSocket Execution Prototype

An experiment in event-driven software design connecting directly to the Deriv WebSocket API. Designed to test real-time tick streaming, continuous volatility measurement, and automated ping-pong reconnection logic under network drops.

  • Zero Credential Persistence: Token authentication handled purely in ephemeral memory; never stored in plaintext or logged.
  • Tick Frequency Analysis: Aggregates 1-second price ticks into rolling statistical bands for mean-reversion evaluation.
  • Fail-Safe Order Verification: Multi-stage handshake confirming order acceptance before clearing execution locks.
